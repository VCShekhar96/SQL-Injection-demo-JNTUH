# SQL Injection Training Lab

## Project Overview

This project demonstrates SQL injection risks
and secure database programming using Python
and SQLite.

## Technologies

- Python 3
- SQLite
- SQL
- Parameterized Queries
- PBKDF2 Password Hashing

## Features

1. Database creation
2. Sample user registration
3. Password hashing
4. User authentication
5. Parameterized SQL queries
6. Secure database connection

## Security Controls

- Parameterized SQL queries
- Password hashing
- Generic login error messages
- Database connection management
- Least privilege principles

## Execution

Step 1:
python setup.py

Step 2:
python secure_login.py
